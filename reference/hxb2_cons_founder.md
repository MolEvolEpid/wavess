# HXB2, consensus, and founder alignment

Full-genome alignment of HXB2, consensus sequence, and DEMB11US006
(founder)

## Usage

``` r
hxb2_cons_founder
```

## Format

### `hxb2_cons_founder`

An `ape` DNAbin object with 3 DNA sequences of length 1563 including the
full-genome sequence for HXB2, the consensus sequence, and DEMB11US006
(founder)
