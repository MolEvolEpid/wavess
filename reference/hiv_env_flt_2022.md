# HIV1 ENV alignment

The 2022 HIV1 ENV FLT web alignment from the LANL HIV database

## Usage

``` r
hiv_env_flt_2022
```

## Format

### `hiv_env_flt_2022`

An `ape` DNAbin object with 10 DNA sequences of length 3993. If you
would like to download the entire set of 6,741 sequences, please visit
the link below.

## Source

<https://www.hiv.lanl.gov/content/sequence/NEWALIGN/align.html>
