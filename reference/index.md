# Package index

## Pre-processing

- [`define_growth_curve()`](https://molevolepid.github.io/wavess/reference/define_growth_curve.md)
  : Define active infected cell growth curve
- [`define_sampling_scheme()`](https://molevolepid.github.io/wavess/reference/define_sampling_scheme.md)
  : Define sampling scheme
- [`slice_aln()`](https://molevolepid.github.io/wavess/reference/slice_aln.md)
  : Slice alignment
- [`extract_seqs()`](https://molevolepid.github.io/wavess/reference/extract_seqs.md)
  : Extract founder (and reference) sequence from an alignment
- [`estimate_q()`](https://molevolepid.github.io/wavess/reference/estimate_q.md)
  : Calculate nucleotide substitution probabilities
- [`calc_q_from_rates()`](https://molevolepid.github.io/wavess/reference/calc_q_from_rates.md)
  : Calculate Q matrix from nucleotide substitution rates
- [`identify_conserved_sites()`](https://molevolepid.github.io/wavess/reference/identify_conserved_sites.md)
  : Identify conserved sites
- [`get_epitope_frequencies()`](https://molevolepid.github.io/wavess/reference/get_epitope_frequencies.md)
  : Get epitope frequencies
- [`sample_epitopes()`](https://molevolepid.github.io/wavess/reference/sample_epitopes.md)
  : Sample epitopes
- [`map_ref_founder()`](https://molevolepid.github.io/wavess/reference/map_ref_founder.md)
  : Map reference and founder sequence positions

## Main simulator

- [`create_python_venv()`](https://molevolepid.github.io/wavess/reference/create_python_venv.md)
  : Create python virtual environment and dependencies in conda or
  virtualenv environment
- [`remove_python_venv()`](https://molevolepid.github.io/wavess/reference/remove_python_venv.md)
  : Uninstall the wavess environment
- [`run_wavess()`](https://molevolepid.github.io/wavess/reference/run_wavess.md)
  : Run wavess

## Output analysis

- [`calc_div_metrics()`](https://molevolepid.github.io/wavess/reference/calc_div_metrics.md)
  : Calculate sequence-based diversity and divergence
- [`calc_tr_stats()`](https://molevolepid.github.io/wavess/reference/calc_tr_stats.md)
  : Calculate tree summary statistics
